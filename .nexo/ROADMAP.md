# NEXO SPACE AI — Roadmap

## Phase 0 — Core foundation
- Import the OpenPlan3D engine.
- Preserve MIT license and compatible project formats.
- Apply NEXO visual identity without coupling it to geometry code.
- Validate production build.

## Phase 1 — NEXO workspace
- Premium project dashboard.
- Spanish-first product copy.
- Project metadata: client, location, typology, status, designer.
- Cloud-ready project abstraction while retaining local fallback.

## Phase 2 — TEMPLO library
- Materials catalog: Pelikano, Duratex, Madecor and custom references.
- Furniture catalog with supplier, dimensions, finish and cost metadata.
- Favorites, collections and project palettes.

## Phase 3 — Design Copilot
- Natural-language editing commands.
- Layout variants with constraints.
- Material/style suggestions.
- Project-aware assistant that reads rooms, dimensions and selected objects.

## Phase 4 — Commercial layer
- Quantity takeoff.
- Budget and quotation generator.
- Technical sheets.
- Client presentation and comparison links.
- Approval/comments workflow.

## Phase 5 — Render pipeline
- One-click scene export.
- ComfyUI / cloud rendering connectors.
- Photorealistic render queue.
- Before/after and option A/B/C comparisons.
